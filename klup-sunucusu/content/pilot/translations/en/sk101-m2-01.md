# What changes in a packet's layers?

> Editorial draft. Technical and language review are pending; this is not published pilot content.

## The case

While a web request carries application data, the transport and network layers take on different jobs. Reading the packet headers is not the same as reading on whose behalf the application is acting. Rather than memorising layer names, ask what each field describes. Encrypted traffic may hide the application content, but some metadata about the connection can still be seen.

## Synthetic evidence

```text
Network destination: 192.0.2.40
Transport: TCP port 443
Application: HTTPS
```

## Investigation steps

1. Find the network address
2. Separate the transport fields
3. Assess the application observation separately

Key term: **encapsulation**.

## Remember

- Network and application identities are assessed in separate contexts.
- Keep observations separate from assumptions.
- Record the evidence, the scope and the reason for the next step.
