# Which question does a TLS certificate not answer?

> Editorial draft. Awaiting technical and language review; this is not published pilot content.

## Incident

TLS helps protect the confidentiality and integrity of a connection. Certificate verification includes checks such as name matching, the chain of trust and validity. But a lookalike domain belonging to an attacker can also obtain a valid certificate. So the padlock in the browser doesn't on its own prove that the address you visited is the organisation you expected.

## Synthetic evidence

```text
Expected: mavifener.example
Visited: mavifener-help.example
Certificate valid for visited name
```

## Review steps

1. Identify the expected domain name
2. Compare the connection and the certificate name
3. Verify the organisation's link independently

Key concept: **TLS**.

## Remember

- Whether the domain name belongs to the organisation must be verified independently.
- Separate observations from assumptions.
- Record the evidence, the scope and the reason for the next step.
