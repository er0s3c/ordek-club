# Which fields belong in an HTTP request?

> Editorial draft. Technical and language review are pending; this is not published pilot content.

## The case

An HTTP request expresses what the client wants through its method, target and headers. A body does not have to be present in every request. In this HTTP/1.1 example, the Host header specifies the target authority. When you reproduce a request, use only synthetic data from the authorised training environment; do not share real session cookies.

## Synthetic evidence

```text
GET /events HTTP/1.1
Host: portal.mavifener.example
```

## Investigation steps

1. Choose the method and path
2. Specify the Host header
3. Record and interpret the response

Key term: **request**.

## Remember

- The method, the target and the Host header must be read together.
- Keep observations separate from assumptions.
- Record the evidence, the scope and the reason for the next step.
