# Why do defence layers complement each other?

> Editorial draft. Technical and language review are pending. This is not published pilot content.

## The case

A single security control does not cover every path to failure. Authentication, authorisation, logging and backups serve different purposes. When one layer fails, you need to test whether another remains effective. A tick on a checklist should not count as proof of a defence that actually works.

## Synthetic evidence

```text
Authentication: enabled
Object authorization: missing
Audit log: enabled
```

## Investigation steps

1. Separate the purposes of controls
2. Identify dependencies and gaps
3. Verify by testing a failure scenario

Key term: **defense-in-depth**.

## Remember

- The presence of one layer does not make up for a gap in another.
- Keep observations separate from assumptions.
- Record evidence, scope, and the reason for the next step.
