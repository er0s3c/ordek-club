# What do we look at in the browser network panel?

> Editorial draft. Technical and language review are pending; this is not published pilot content.

## The case

Developer tools let you inspect the requests a page makes, the status codes and the timing. A button not being visible in the browser does not prove that the corresponding server operation is authorised. Do the inspection with your own training account; remove cookies and personal data from exported captures. Record the context of the request as well, not just a screenshot.

## Synthetic evidence

```text
Network panel
GET /events -> 200
GET /admin -> 403
Cookie: [redacted]
```

## Investigation steps

1. Select the relevant request
2. Inspect the header and the response
3. Remove secrets before sharing

Key term: **DevTools**.

## Remember

- A client-side view does not prove server access control.
- Keep observations separate from assumptions.
- Record the evidence, the scope and the reason for the next step.
