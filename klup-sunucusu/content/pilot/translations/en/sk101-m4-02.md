# Whose access does the 600 permission restrict?

> Editorial draft. Technical and language review are pending; this is not published pilot content.

## The case

Linux base permissions carry separate bits for the file owner, the group and other users. 600 gives the owner read and write permission while keeping the group and others out. ACLs, privileged users and parent directory permissions can also affect real access. In this lab the file owner is the student; we are changing only the base file mode.

## Synthetic evidence

```text
Before: -rw-r--r-- student student incident.txt
Required: owner read/write only
```

## Investigation steps

1. Read the owner and the current mode
2. Apply the least necessary mode
3. Re-verify the result

Key term: **permissions**.

## Remember

- The base file mode should be 600.
- Keep observations separate from assumptions.
- Record the evidence, the scope and the reason for the next step.
