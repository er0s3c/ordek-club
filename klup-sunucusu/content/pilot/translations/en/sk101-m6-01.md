# Can you tell encoding, hashing and encryption apart?

> Editorial draft. Awaiting technical and language review; this is not published pilot content.

## Incident

Base64 turns data into another representation; it provides no confidentiality. A cryptographic digest is used for integrity comparisons, and its normal purpose is not to be reversed. Encryption, by contrast, provides confidentiality in a form that can be reversed with the right key. Ask what security goal a tool meets, not what it is called.

## Synthetic evidence

```text
Representation: Base64
Integrity check: SHA-256 digest
Confidentiality: encryption with managed keys
```

## Review steps

1. Identify the security goal
2. Distinguish the property of the mechanism
3. Choose the control that fits the goal

Key concept: **encoding**.

## Remember

- Base64 is not a confidentiality control.
- Separate observations from assumptions.
- Record the evidence, the scope and the reason for the next step.
