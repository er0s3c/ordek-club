# How do you tell symmetric and asymmetric keys apart?

> Editorial draft. Awaiting technical and language review; this is not published pilot content.

## Incident

Symmetric operations use a shared secret key; asymmetric structures use a related public key and private key. Protecting the private key and verifying who owns the public key are separate responsibilities. Knowing the name of the algorithm doesn't prove that secure key management is in place. Don't put real secrets in lesson files.

## Synthetic evidence

```text
Public key: shareable after identity verification
Private key: restricted access
Training data only
```

## Review steps

1. Distinguish the key types
2. Examine storage and access
3. Verify the identity binding

Key concept: **key**.

## Remember

- The private key must be protected; the identity binding must be verified separately.
- Separate observations from assumptions.
- Record the evidence, the scope and the reason for the next step.
