# Why does the directory you are in matter in Linux?

> Editorial draft. Technical and language review are pending; this is not published pilot content.

## The case

Relative paths are interpreted against the current working directory. The same file name can show different data in different directories. In an investigation, confirm where you are first, then read the file without making changes. Moving up to a parent directory or running a search does not grant permission to inspect files outside the scope.

## Synthetic evidence

```text
$ pwd
/home/student
$ ls
incident.txt notes/
```

## Investigation steps

1. Confirm the working directory
2. List the target file
3. Inspect without modifying the content

Key term: **directory**.

## Remember

- The meaning of a relative path depends on the working directory.
- Keep observations separate from assumptions.
- Record the evidence, the scope and the reason for the next step.
