# Are threat, vulnerability and risk the same thing?

> Editorial draft. Technical and language review are pending; this is not published pilot content.

## The case

Zeytinlik Market's report directory does not ask for authentication. This misconfiguration is a vulnerability; an unauthorised person using it is the threat scenario. A risk assessment considers likelihood and business impact together. Counting flaws alone does not explain which fix should come first.

## Synthetic evidence

```text
Asset: customer delivery report
Control: authentication disabled
Exposure: shared training network
```

## Investigation steps

1. Define the asset
2. Write the threat scenario
3. Assess impact and likelihood

Key term: **risk**.

## Remember

- The asset, likelihood and impact must be assessed together.
- Keep observations separate from assumptions.
- Record the evidence, the scope and the reason for the next step.
