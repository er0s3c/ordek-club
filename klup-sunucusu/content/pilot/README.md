# SK-101 editör taslakları

28 ders ve 7 vaka labı, TR/EN ayrı dosyalarla hazırlanmıştır. Yayımlanmış içerik değildir. Hiçbir dosyada bağımsız teknik/dil incelemesi yapılmış gibi onay verilmez. İnceleyenler kaynakları, etkinlikleri, süre tahminlerini ve dil doğruluğunu tamamladıktan sonra iki dil birlikte ana akademi manifestine alınmalıdır.

Komut Hattı için şu an tek gerçek Linux izin labı uygulanmıştır; diğer vaka labları gerçek terminal oturumu gibi sunulmamalıdır. Bu taslaklar Docker imajına veya canlı içe aktarmaya otomatik eklenmez.
