# Campus events

> Events you can join even if you aren't enrolled in the Academy. **All you need is to be able to use a web browser.**

::cizgi[p-08-sahne]

## 🕵️ Campus 404 — A Digital Mystery

![Four event booths in a night campus courtyard: a mystery box, a detective board, a lab bench and a safe-shaped password stand](../gorseller/p-08-b.webp)

**90–120 min · team · any department**

A file has disappeared from the archive of a fictional campus. Follow it through five clues:
solve the hidden message, tell the fake email apart, find the clue in the image, catch the mistake on the web page,
complete the timeline of the incident. A new story every year.

## 🔍 Cyber Detective
A deleted note, a screenshot, a fake social media account and file metadata.
People from non-technical departments contribute too, through reasoning and verification.

## 🛠️ Hack the Campus Lab
In a fictional university web application an instructor demonstrates a security flaw;
you observe the impact, then test whether **the fix** actually works.

## 🔐 The Story Behind the Password
An interactive stand: tell phishing messages apart, compare MFA methods.
A real password or login detail is **never** requested.

The event calendar is in the club announcements and on the home page.
