# Roadmap and calendar

> The programme runs for two semesters. With event and holiday weeks included, that comes to about **33 weeks** on the calendar.

::cizgi[p-02-sahne]

## Semester 1 — Shared foundation

| Week | Topic |
|---|---|
| 1 | Introduction to cyber security |
| 2 | Ethics, law and privacy |
| 3 | Operating system security |
| 4 | Linux |
| 5–6 | Networking fundamentals |
| 7 | Web technologies |
| 8 | Python |
| 9 | Cryptography |
| 10 | OSINT |
| 11 | Attack and defence fundamentals |
| 12 | Mini CTF and assessment |
| 13 | Free practice / catch-up |
| 14 | 🎉 Campus 404 event |
| 15 | Specialisation choice |

## Semester 2 — Specialisation and project

| Week | Topic |
|---|---|
| 16–27 | The 12 lessons of the path you chose |
| 28–33 | The 6 stages of the capstone project and Demo Day |

## Tip

If you miss a week, don't panic: week 13 is a **catch-up week** for exactly that.
