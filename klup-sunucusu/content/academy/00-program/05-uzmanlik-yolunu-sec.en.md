# Which specialisation path suits you?

> In week 15 you choose **one** path. You don't have to learn them all; going deep is worth more.

::cizgi[p-05-sahne]

| Path | What excites you | Prerequisite |
|---|---|---|
| **A — Web and API Security** | Finding where a site breaks | HTTP, web, Linux |
| **B — Network and System Security** | Understanding networks, servers, Active Directory | Networking, Linux, Windows |
| **C — SOC, Incident Response, Digital Forensics** | Investigating alerts, tracing an attack | Operating systems, networking, reading logs |
| **D — OSINT and Threat Intelligence** | Verifying information, analysing attacker behaviour | OSINT, networking, Linux |
| **E — Artificial Intelligence and LLM Security** | Seeing how chatbots and AI agents get tricked | APIs, Python, web |
| **F — Mobile, IoT and Embedded Systems** | Opening up apps and smart devices | Operating systems, networking, programming |
| **G — Malware and Reverse Engineering** | Working out what a program actually does | Linux, Windows, Python |

## Not sure? Ask yourself three questions

1. In the foundation part, which week did you **not notice how the time passed**?
2. Which pulls you more: **finding** (A, B, F, G), **defending** (C) or **investigating** (D, E)?
3. Which file would you like to see in your portfolio as your capstone output?

An introduction page for every path: [Specialisation paths](../02-uzmanlik/).

## Remember

No path is "better". Security teams need **all** of these roles.
