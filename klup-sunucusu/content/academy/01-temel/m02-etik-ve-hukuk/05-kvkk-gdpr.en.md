# TRNC, Türkiye and the EU: comparing data protection

> If an application is developed in the TRNC and offered to users in Türkiye and Europe,
> it may need to comply with **more than one** set of data protection rules.

::cizgi[m02-05-sahne]

| | TRNC | Türkiye | European Union |
|---|---|---|---|
| **Regulation** | Kişisel Verilerin Korunması Yasası | KVKK (Law No. 6698) | GDPR (General Data Protection Regulation) |
| **Common principle** | Purpose limitation, data minimisation, security | The same | The same |
| **Standout feature** | The data controller's security obligation | Registration with the Board (VERBİS) and breach notification | Breach notification within 72 hours, high fines |
| **Who does it apply to?** | Those processing data in the TRNC | Those processing data in Türkiye | **Anyone** processing the data of people in the EU |

> ⚖️ **Instructor note:** Check the official texts for details and current amendments.

## A common language: 5 principles

![Five objects guarding a personal data vault: a key and a sealed document, a signpost pointing one way, a small measuring cup, an hourglass and a shield](../../gorseller/m02-05-b.webp)

1. **Lawfulness** — No processing without a basis (consent, contract, legal obligation…).
2. **Purpose limitation** — Data collected for a scholarship is not used for advertising.
3. **Minimisation** — Only as much data as needed.
4. **Storage period** — Deleted once the need ends.
5. **Security** — Encryption, access control, keeping records.

## Why should a security person care?

A data breach is not just a technical incident; it can create a **legal notification obligation**.
Incident response plans (Path C) take these periods into account.

## ✅ Remember

- The heart of all three regulations is the same: purpose, minimisation, security.
- The GDPR can apply wherever the data of people in the EU is processed.
- A breach = a technical incident + a legal obligation.
