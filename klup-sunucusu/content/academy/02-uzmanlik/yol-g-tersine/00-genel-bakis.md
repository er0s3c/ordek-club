# Yol G — Zararlı Yazılım Analizi ve Tersine Mühendislik

> Bir program **gerçekte** ne yapıyor? Kaynak kodu olmadan öğrenmenin sanatı.

![Fidyeci Ferhat, cam bir muhafaza kutusunun içinde katman katman sökülen parlayan bir programa öfkeyle bakıyor](../../gorseller/g-00-a.webp)

**Ön koşul:** Linux (M04), Windows (M03), Python (M07)

## 12 ders

| # | Ders | Tek cümleyle |
|---|---|---|
| G01 | Tersine mühendisliğin temelleri | Statik ve dinamik analiz, güvenli ortam |
| G02 | Windows iç yapısı | Process, DLL, PE biçimi |
| G03 | Assembly temelleri | Register, stack, kontrol akışı |
| G04 | Statik analiz | Ghidra ile import tabloları ve strings |
| G05 | Dinamik analiz | Debugger, breakpoint, API izleme |
| G06 | .NET analizi | IL ve decompile edilmiş kod |
| G07 | Zararlı yazılım türleri | Trojan, ransomware, kalıcılık göstergeleri |
| G08 | Davranış analizi | Dosya, registry, ağ izleri ve IOC |
| G09 | Bellek güvenliği | Buffer overflow mantığı ve güvenli bellek |
| G10 | Exploit geliştirme temelleri | Crash analizi, ASLR/DEP — yalnız eğitim programlarında |
| G11 | Tespit | YARA ve davranışsal göstergeler |
| G12 | Final | Eğitmen örneği için analiz raporu |

## Bitirme çıktısı

**Zararlı yazılım analiz raporu** veya tersine mühendislik teknik dosyası.

## Güvenlik

Analiz edilen tüm örnekler **eğitmen tarafından eğitim için hazırlanır** ve internete bağlı olmayan,
geri alınabilir sanal makinelerde incelenir. Gerçek zararlı yazılım indirmek veya paylaşmak bu yolun parçası değildir.
